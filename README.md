## Задача 1. Приветствие пользователя

**Постановка задачи:**
Напишите программу, которая запрашивает у пользователя имя и выводит на экран приветственное сообщение с использованием этого имени.

**Математическая модель:**
Не требуется.

**Список идентификаторов:**
| Имя переменной | Тип данных | Смысловое обозначение |
|----------------|------------|-----------------------|
| username       | String     | Имя пользователя      |

**Код программы:**
```rust
use std::io;

fn main() {
    println!("Введите ваше имя:");

```

**Результаты выполненной работы:**

## Задача 3. Функция для вычисления длины строки

**Постановка задачи:**
Напишите функцию, которая принимает строку и возвращает ее длину (количество символов). Затем вызовите эту функцию с различными строками.

**Математическая модель:**
f(s) = len(s), где s - входная строка

**Список идентификаторов:**
| Имя переменная | Тип данных | Смысловое обозначение |
|----------------|------------|-----------------------|
| text           | &str       | Текстовая строка      |

**Код программы:**
```rust
fn calculate_length(text: &str) -> usize {
    text.chars().count()
}

fn main() {
    let texts = vec![
        "Привет",
        "RustLang",
        "Тестирование",
        "A",
        "123",
    ];
    
    for text in texts {
        let length = calculate_length(text);
        println!("'{}' - длина: {}", text, length);
    }
}
```

**Результаты выполненной работы:**
```
'Привет' - длина: 6
'RustLang' - длина: 8
'Тестирование' - длина: 11
'A' - длина: 1
'123' - длина: 3
```

## Задача 5. Числа Фибоначчи

**Постановка задачи:**
Напишите программу, которая запрашивает у пользователя число N и выводит на экран N-ное число Фибоначчи. Используйте рекурсию для решения этой задачи.

**Математическая модель:**
F(0) = 0
F(1) = 1
F(n) = F(n-1) + F(n-2) для n ≥ 2

**Список идентификаторов:**
| Имя переменной | Тип данных | Смысловое обозначение |
|----------------|------------|-----------------------|
| num            | u32        | Порядковый номер      |

**Код программы:**
```rust
use std::io;

fn fib(n: u32) -> u64 {
    match n {
        0 => 0,
        1 => 1,
        _ => fib(n - 1) + fib(n - 2),
    }
}

fn main() {
    println!("Введите номер числа:");
    
    let mut input = String::new();
    
    io::stdin()
        .read_line(&mut input)
        .unwrap();
    
    let num: u32 = input.trim().parse().unwrap();
    
    let result = fib(num);
    println!("Число Фибоначчи №{} = {}", num, result);
}
```

**Результаты выполненной работы:**
```
Введите номер числа:
8
Число Фибоначчи №8 = 21
```

## Задача 6. Перечисление дней недели

**Постановка задачи:**
Реализуйте перечисление DayOfWeek для дней недели. Напишите функцию, которая принимает день недели и возвращает следующий день. Обработайте случаи перехода на следующий день недели, если текущий день – воскресенье.

**Математическая модель:**
Не требуется.

**Список идентификаторов:**
| Имя переменной | Тип данных | Смысловое обозначение |
|----------------|------------|-----------------------|
| today          | DayOfWeek  | Сегодняшний день      |

**Код программы:**
```rust
#[derive(Debug)]
enum DayOfWeek {
    Понедельник,
    Вторник,
    Среда,
    Четверг,
    Пятница,
    Суббота,
    Воскресенье,
}

impl DayOfWeek {
    fn next(&self) -> DayOfWeek {
        match self {
            DayOfWeek::Понедельник => DayOfWeek::Вторник,
            DayOfWeek::Вторник => DayOfWeek::Среда,
            DayOfWeek::Среда => DayOfWeek::Четверг,
            DayOfWeek::Четверг => DayOfWeek::Пятница,
            DayOfWeek::Пятница => DayOfWeek::Суббота,
            DayOfWeek::Суббота => DayOfWeek::Воскресенье,
            DayOfWeek::Воскресенье => DayOfWeek::Понедельник,
        }
    }
}

fn main() {
    let days = [
        DayOfWeek::Понедельник,
        DayOfWeek::Вторник,
        DayOfWeek::Среда,
        DayOfWeek::Четверг,
        DayOfWeek::Пятница,
        DayOfWeek::Суббота,
        DayOfWeek::Воскресенье,
    ];
    
    for day in days.iter() {
        let tomorrow = day.next();
        println!("{:?} -> {:?}", day, tomorrow);
    }
}
```

**Результаты выполненной работы:**
```
Понедельник -> Вторник
Вторник -> Среда
Среда -> Четверг
Четверг -> Пятница
Пятница -> Суббота
Суббота -> Воскресенье
Воскресенье -> Понедельник
```

## Задача 7. Структура Product и перечисление Category

**Постановка задачи:**
Создайте структуру Product с полями name, price и category, а также перечисление (enum) Category для категорий товаров. Напишите метод для вывода информации о продукте и ассоциированную функцию для подсчета общей суммы товаров в заданной категории из массива продуктов.

**Математическая модель:**
Не требуется.

**Список идентификаторов:**
| Имя переменной | Тип данных | Смысловое обозначение |
|----------------|------------|-----------------------|
| item           | Product    | Товар                 |
| group          | Category   | Группа товаров        |

**Код программы:**
```rust
#[derive(Debug, Clone, PartialEq)]
enum Category {
    Техника,
    Мебель,
    Продукты,
    Одежда,
}

#[derive(Debug, Clone)]
struct Product {
    name: String,
    price: f64,
    category: Category,
}

impl Product {
    fn print(&self) {
        println!("{}: {} руб.", self.name, self.price);
    }
    
    fn total(products: &[Product], category: Category) -> f64 {
        products
            .iter()
            .filter(|p| p.category == category)
            .map(|p| p.price)
            .sum()
    }
}

fn main() {
    let items = vec![
        Product {
            name: String::from("Холодильник"),
            price: 35000.0,
            category: Category::Техника,
        },
        Product {
            name: String::from("Диван"),
            price: 25000.0,
            category: Category::Мебель,
        },
        Product {
            name: String::from("Молоко"),
            price: 80.0,
            category: Category::Продукты,
        },
        Product {
            name: String::from("Телевизор"),
            price: 45000.0,
            category: Category::Техника,
        },
        Product {
            name: String::from("Куртка"),
            price: 5000.0,
            category: Category::Одежда,
        },
    ];
    
    println!("Список товаров:");
    for item in &items {
        item.print();
    }
    
    println!("\nОбщая стоимость по категориям:");
    let categories = [
        Category::Техника,
        Category::Мебель,
        Category::Продукты,
        Category::Одежда,
    ];
    
    for category in categories.iter() {
        let total = Product::total(&items, category.clone());
        println!("{:?}: {:.1} руб.", category, total);
    }
}
```

**Результаты выполненной работы:**
```
Список товаров:
Холодильник: 35000 руб.
Диван: 25000 руб.
Молоко: 80 руб.
Телевизор: 45000 руб.
Куртка: 5000 руб.

Общая стоимость по категориям:
Техника: 80000.0 руб.
Мебель: 25000.0 руб.
Продукты: 80.0 руб.
Одежда: 5000.0 руб.
```

## Задача 8. Структура Employee и перечисление Position

**Постановка задачи:**
Создайте структуру Employee с полями name, position, salary, а также перечисление Position для должностей сотрудников. Напишите функцию, которая принимает вектор сотрудников и возвращает вектор сотрудников заданной должности.

**Математическая модель:**
Не требуется.

**Список идентификаторов:**
| Имя переменной | Тип данных | Смысловое обозначение |
|----------------|------------|-----------------------|
| worker         | Employee   | Сотрудник             |
| job            | Position   | Должность             |

**Код программы:**
```rust
#[derive(Debug, Clone, PartialEq)]
enum Position {
    Директор,
    Инженер,
    Бухгалтер,
    Водитель,
}

#[derive(Debug, Clone)]
struct Employee {
    name: String,
    position: Position,
    salary: u32,
}

impl Employee {
    fn info(&self) {
        println!("{} ({:?}) - {} руб.", self.name, self.position, self.salary);
    }
}

fn filter(employees: &[Employee], position: Position) -> Vec<Employee> {
    employees
        .iter()
        .filter(|e| e.position == position)
        .cloned()
        .collect()
}

fn main() {
    let workers = vec![
        Employee {
            name: String::from("Семенов А.В."),
            position: Position::Директор,
            salary: 150000,
        },
        Employee {
            name: String::from("Козлов П.Р."),
            position: Position::Инженер,
            salary: 90000,
        },
        Employee {
            name: String::from("Морозова Е.Л."),
            position: Position::Бухгалтер,
            salary: 70000,
        },
        Employee {
            name: String::from("Волков Д.С."),
            position: Position::Инженер,
            salary: 95000,
        },
        Employee {
            name: String::from("Захаров М.И."),
            position: Position::Водитель,
            salary: 50000,
        },
    ];
    
    println!("Все сотрудники:");
    for worker in &workers {
        worker.info();
    }
    
    println!("\nИнженеры:");
    let engineers = filter(&workers, Position::Инженер);
    for eng in &engineers {
        eng.info();
    }
    
    println!("\nБухгалтеры:");
    let accountants = filter(&workers, Position::Бухгалтер);
    for acc in &accountants {
        acc.info();
    }
}
```

**Результаты выполненной работы:**
```
Все сотрудники:
Семенов А.В. (Директор) - 150000 руб.
Козлов П.Р. (Инженер) - 90000 руб.
Морозова Е.Л. (Бухгалтер) - 70000 руб.
Волков Д.С. (Инженер) - 95000 руб.
Захаров М.И. (Водитель) - 50000 руб.

Инженеры:
Козлов П.Р. (Инженер) - 90000 руб.
Волков Д.С. (Инженер) - 95000 руб.

Бухгалтеры:
Морозова Е.Л. (Бухгалтер) - 70000 руб.
```
